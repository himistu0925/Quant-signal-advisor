# 퀀트 신호 어드바이저 — 가정 검증 (투자자 페르소나 인터뷰)

> `plan.md`의 TL;DR("주관적 판단 대신 보조지표 수치만으로 매수/매도 후보 신호를 생성")이 전제하는 가정들을, 서로 다른 투자 성향의 페르소나 5명을 서브에이전트로 세워 검증했습니다.

## 1. 가정들

- A: 개인 투자자는 매수/매도 타이밍을 놓고 늘 고민한다(스스로 확신을 갖기 어렵다)
- B: 감정/직감이 아닌 객관적 지표 기반 신호를 추천받고 싶어한다
- C: 혼자 판단할 때(변동성 장세, 정보 부족 상황)는 더 흔들리고 고민하게 된다

## 2. 질문들

- Q1: 평소에 매수/매도 타이밍을 정하는 게 어렵거나 스트레스로 느껴지나요? (A)
- Q2: 자신의 직감/판단대로 매매하는 것을 선호하나요, 아니면 지표나 다른 사람 의견을 참고하고 싶나요? (A, B)
- Q3: 혼자 판단할 때와 커뮤니티/전문가 의견이 있을 때 매매 결정이 크게 달라지나요? (C)

## 4. 답변 요약

### Q1. 매수/매도 타이밍이 어렵거나 스트레스인가?
- **강지훈**: 급락 시 패닉셀 경험, 아직도 스트레스
- **오세훈**: 6년차인데도 여전히 어려움, 특히 익절 타이밍
- **한미영**: 15년차인데도 매도 타이밍(조정 vs 추세전환 구분)이 어려움
- **배준서**: 매수보다 **매도 타이밍**이 더 스트레스, 업무 중이라 알림에 의존해도 판단은 매번 새로 고민
- **정하윤**: 급락엔 패닉셀, 급등엔 추격매수 — 거의 매일 스트레스

→ **경력·연차와 무관하게 전원이 스트레스를 확인** — 가정 A는 강하게 확인됨. 다만 **"매수"보다 "매도" 타이밍이 더 큰 고통 지점**이라는 게 공통적으로 나타남(3명이 명시적으로 언급). `plan.md` 7절 지표표는 매수/매도 신호를 대칭적으로 다루지만, 실제 사용자 고통은 매도 쪽에 더 쏠려 있을 가능성이 있음.

### Q2. 직감 vs 지표/타인 의견?
- **강지훈**: 직감 매매는 대부분 손실 → 지표/데이터 선호로 전환
- **오세훈**: 기본적으로 지표 기반 원칙주의자, 단 급변장에선 감정에 룰이 깨짐
- **한미영**: 펀더멘털(재무제표·실적) 선호, **단기 기술적 지표는 "도박처럼 느껴져서" 회의적** — 유일한 예외
- **배준서**: 지표 기반 선호, 본인이 직접 스크립트로 자동 체크
- **정하윤**: 감정 매매로 손실 경험 후 지표/데이터 기반 신호 선호로 전환

→ **5명 중 4명이 명확히 지표 기반 신호를 선호** — 가정 B 확인. 그러나 **장기 가치투자자(한미영)에게는 이 가정이 성립하지 않음** — 기술적 지표 자체를 신뢰하지 않기 때문. 즉 이 도구의 가치제안은 "기술적 지표를 신뢰하는 트레이더" 세그먼트에 한정되며, 펀더멘털 중심 장기투자자는 애초에 타겟이 아님을 시사.

### Q3. 혼자 vs 커뮤니티/전문가 의견 있을 때?
- **강지훈**: 혼자면 확신 없음 → 커뮤니티 글 하나에 바로 실행(때로 손실로 이어짐)
- **오세훈**: 변동성 장세에서 혼자면 판단 미룸/손절 지연 → 타인 의견 있으면 "검증받는 느낌"으로 더 빠르고 단호하게 결정
- **한미영**: 평상시엔 본인 판단 유지, 급변 뉴스 때는 혼자 결정이 힘들어짐
- **배준서**: 새벽 시간대(미국 장중) 혼자 판단 시 크게 흔들림, 참고할 기준이 있으면 안정
- **정하윤**: 혼자면 패닉셀/추격매수로 흔들림, 참고 근거 있으면 침착해짐

→ **전원 확인** — 가정 C 성립. 핵심 통찰은 **"혼자일 때 흔들리는 이유는 신중해서가 아니라 근거(anchor)가 없어서"**라는 점. 커뮤니티 의견이 그 근거 역할을 대신하고 있지만, 강지훈의 사례처럼 **타인 의견은 틀릴 수 있어 오히려 손실로 이어짐** — 이 지점이 정확히 객관적 신호(지표 기반)가 커뮤니티 의견보다 안전하게 채울 수 있는 공백.

## 5. 확인한 사실들 (종합)

1. **경력과 무관하게 매수/매도 판단은 항상 스트레스이며, 특히 매도 타이밍이 더 고통스럽다.** `plan.md` 11절 디스코드 알림 설계가 매수/매도 신호를 동일 비중으로 다루는데, 실사용자 관점에선 매도 신호 알림의 근거 설명(왜 지금 팔아야 하는지)을 더 두텁게 설계할 필요가 있음.
2. **"지표 기반 신호를 원한다"는 가정은 기술적 트레이더층에서는 강하게 성립하지만, 펀더멘털 중심 장기투자자에게는 성립하지 않는다.** 이 도구의 타겟은 "기술적 지표를 신뢰하는 개인 트레이더"로 명확히 좁혀야 하며, 장기 가치투자자용 지표(재무 팩터 등)는 별도 트랙으로 취급해야 함.
3. **혼자 판단할 때 흔들리는 원인은 "정보 부족" 자체가 아니라 "판단을 검증해줄 근거(anchor)의 부재"다.** 현재 이 근거를 커뮤니티/유튜브 의견이 대신하고 있고, 이는 종종 틀린 정보를 따라가게 만들어 손실로 이어짐 — 신호 알림이 "틀릴 수도 있는 타인 의견"보다 **일관되고 재현 가능한 근거**를 제공한다는 점이 핵심 차별점.
4. **장중 실시간 확인이 어려운 사용자층(직장인·개발자)에게 디스코드 알림 방식 자체가 정확히 필요한 형태로 확인됨.** `plan.md` 3절의 "PC 전원과 무관하게 동작" 요구사항 및 15~30분 주기 알림 설계가 실제 페인포인트(배준서: 업무 중 시세 확인 불가, 강지훈/정하윤: 밤 시간대 미국 장 대응 어려움)와 정합적임.
5. **숙련자(오세훈)조차 급변장에서 본인 룰을 어긴다는 점**은, 신호 시스템이 "판단을 도와주는 참고자료"를 넘어 **쿨다운/중복 억제 로직(9절)처럼 감정적 이탈을 막는 장치**로도 기능해야 함을 시사.

## 6. 제품 방향 시사점

- **매도 신호의 설명 근거를 매수 신호보다 더 상세하게 노출**하는 것을 우선 검토 (Q1 결과 반영).
- 타겟 사용자 정의를 **"기술적 지표 신뢰 + 실시간 대응 어려운 개인 트레이더"**로 명시적으로 좁히고, 장기 가치투자자는 스코프 아웃 유지.
- 신호 알림 메시지에 "왜 이 신호를 신뢰할 수 있는지"(백테스트 근거, 캘리브레이션된 임계값 대비 현재 스코어)를 강조해 **커뮤니티 의견보다 신뢰할 수 있는 anchor**라는 포지셔닝을 명확히 할 것.
